# Quadratic Shooter

平方完成トレーニング用Webアプリ。高速に平方完成を行い、タイムを競います。

## 技術スタック
- **Frontend**: Next.js (App Router), React
- **Styling**: Vanilla CSS (Global Styles), Framer Motion
- **Database**: Supabase
- **Deployment**: Vercel

## セットアップ手順

### 1. Supabaseの準備
1. [Supabase](https://supabase.com/) で新しいプロジェクトを作成します。
2. SQL Editor で以下のSQLを実行して、`scores` テーブルを作成します。

```sql
create table scores (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  mode text not null,
  time float8 not null,
  handle_name text default 'Anonymous'
);

-- 読み取りは誰でも可能にする（ランキング表示用）
create policy "Allow public read access" on scores for select using (true);
-- 挿入は誰でも可能にする
create policy "Allow public insert access" on scores for insert with check (true);
-- 削除は認証済みユーザーのみ（またはポリシーなしで管理者キー使用）
-- ※簡易運用のための設定。本来は認証を推奨。
```

### 2. 環境変数の設定
`.env.local` ファイルを作成し、以下の情報を入力します。
(Vercelデプロイ時は、Vercelの管理画面で環境変数を設定してください)

```env
NEXT_PUBLIC_SUPABASE_URL=あなたのSupabaseプロジェクトURL
NEXT_PUBLIC_SUPABASE_ANON_KEY=あなたのSupabase Anon Key
```

### 3. ローカル開発
```bash
npm install
npm run dev
```

### 4. デプロイ
- GitHub にプッシュし、Vercel と連携するだけで公開されます。

## 管理者機能
`/admin` ページからスコアログの確認と削除が可能です。
(※現時点では簡易的な一覧表示のみ。実運用時は認証を追加することを推奨します)
